What you're watching

Every twelve seconds or so, Ethereum produces a block, and this page reads it the instant it lands. The headline number is the base fee: a price per unit of gas that the network sets for itself, with no auction and no miner in the loop. It exists because of EIP-1559, the fee-market upgrade that went live in August 2021, and it is the reason the chart above is usually so smooth — the base fee can only move a little from block to block.

How the fee market actually works

Each block has room for a target amount of gas and a hard cap of twice that. After a block is mined, the protocol looks at how much gas it used. If the block ran fuller than the 50% target, the next block's base fee goes up; if it ran emptier, the base fee comes down. The size of the move is proportional to how far from target the block was, capped at 12.5% in either direction. That is the whole mechanism, and you can watch it happen: the gauge shows how full the last block was, and the "next block base fee" stat is the exact number that rule produces — not a forecast, but the value the node has already committed to.

The clever part is what happens to the base fee once it is paid. It is not handed to the validator — it is burned, destroyed forever, removing that ETH from circulation. Only the small priority tip on top goes to the validator as an incentive to include your transaction. This page multiplies each block's base fee by the gas it used to show the ETH going up in smoke, and keeps a running total for every block since you opened the tab.

How this runs in your browser

There is no backend here. Your browser calls Ethereum's public JSON-RPC directly — eth_feeHistory for the base fee, fullness and tip percentiles across recent blocks, and eth_getBlockByNumber for the latest block's details. It cycles through several no-key public nodes and fails over if one is slow, and it opens on a recent snapshot so you never stare at a blank screen. Nothing is uploaded, no wallet is connected, and it only ever reads — so it physically cannot touch anyone's funds.

Is this a real, live number or a demo?

Real and live. The page opens on a recent snapshot so there is something to look at instantly, then it starts polling actual Ethereum nodes every few seconds and the block feed fills in with real blocks as they are produced.

Why is the base fee so low / high right now?

The base fee simply reflects demand for blockspace. When lots of people are transacting, blocks run fuller than target and the base fee climbs; when the chain is quiet it drifts down toward the floor. Watch the gauge and the chart together and you can see the cause and effect directly.

What is gwei?

A gwei is one-billionth of an ETH, the unit gas prices are quoted in. A base fee of 10 gwei means each unit of gas costs 0.00000001 ETH; a simple transfer uses 21,000 units, so it would cost about 0.00021 ETH in base fee before the tip.

Does it work on mobile?

Yes. It is just reading data and drawing a small chart, so it runs anywhere with a browser and a connection. No wallet app or extension is needed.

Can I trust the cost estimates for a real transaction?

Use them as a live gauge of whether gas is cheap or expensive, not as an exact quote. Real transactions vary in how much gas they use, and your wallet computes the precise fee when you sign. This shows typical costs at the current base fee plus a median tip.
